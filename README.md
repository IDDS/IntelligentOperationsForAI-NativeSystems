# 面向 AI 原生系统的智能运维

Intelligent Operations for AI-Native Systems

中山大学计算机学院研究生校企联合课程 · 2026 秋季学期

本仓库仅发布本课程的授课 Slide PDF，方便课程学习、课堂预习和课后复习。

## 课程简介

课程围绕 AI 原生系统的生产运维问题展开，连接大模型训练与推理、GPU 集群、LLM Serving、可观测性、故障诊断、Agent 运维和知识闭环。课程主线为：

> AI 原生系统基础 → 可观测性与证据 → 异常检测与定位 → 因果诊断 → Agent 治理 → 验证与知识沉淀
